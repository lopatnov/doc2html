# pdf2html

Конвертация PDF-документа в читаемый HTML (UTF-8) с сохранением картинок.

Решает две типичные проблемы «наивных» конвертеров:

- **Кодировки.** Текст извлекается через PyMuPDF (умеет корректно
  разбирать сломанные/кастомные шрифтовые кодировки в PDF), затем
  нормализуется (`NFKC`) и очищается от «мусорных» символов
  Private Use Area (нечитаемые квадратики), которые появляются, когда
  у шрифта в PDF нет корректной ToUnicode-таблицы. Результат всегда
  валидный UTF-8 (`<meta charset="utf-8">`).
- **Картинки.** Все встроенные изображения извлекаются в исходном
  качестве и сохраняются рядом с HTML, в подпапку `images/`, с
  привязкой к странице и порядку внутри неё.

## Установка

Требуется установленный conda (Miniconda/Anaconda).

```bash
install.bat
```

Создаст conda-окружение `pdf2html` (Python 3.11) и поставит зависимости
из `requirements.txt` (PyMuPDF, Pillow, torch, transformers). Модель
подписей к картинкам (`Salesforce/blip-image-captioning-base`, ~1 ГБ)
скачается один раз при первом запуске с включённой генерацией alt-текста.

## Активация окружения

```bash
activate.bat
```

## Использование

```bash
python pdf2html.py input\example.pdf -o output
```

### Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| `input_pdf` | — | Путь к исходному PDF-файлу (обязательный) |
| `-o`, `--output-dir` | `output` | Папка для результата |
| `--save-images` / `--no-save-images` | включено | Сохранять картинки в `<output>/images` |
| `--generate-alt` / `--no-generate-alt` | включено | Генерировать описание картинки офлайн-моделью |

### Поведение флагов

- `--save-images` (вкл) + `--generate-alt` (вкл): `<img src="images/...">`
  с содержательным `alt="..."` (описание картинки).
- `--save-images` (вкл) + `--no-generate-alt`: `<img>` сохраняется,
  но `alt` пустой (без генерации описания).
- `--no-save-images` + `--generate-alt` (вкл): картинка не сохраняется,
  вместо неё в текст вставляется абзац `[Изображение: <описание>]`.
- `--no-save-images` + `--no-generate-alt`: картинка не сохраняется,
  вместо неё — заглушка `[Изображение]`.

### Пример

```bash
activate.bat
python pdf2html.py "input\Веб-дизайн книга Якоба Нильсена.pdf" -o output
```

Результат: `output\Веб-дизайн книга Якоба Нильсена.html` и, если
включено сохранение картинок, `output\images\*.png` (или другой
исходный формат картинки).

## Примечания

- Описания картинок генерируются на английском языке (модель BLIP
  обучена на английских подписях).
- Первый запуск с `--generate-alt` будет заметно медленнее из-за
  загрузки весов модели; при повторных запусках модель берётся из
  локального кеша.
- Для больших PDF (сотни страниц с картинками) генерация подписей —
  самый медленный этап; отключайте её через `--no-generate-alt`, если
  описания не нужны.
